## 📌 About This Repository

This repository brings together my practical coursework in **Artificial Intelligence and Machine Learning**. It follows the course progression, starting with Python and numerical computing, then moving through classical machine learning, neural networks, natural language processing, and computer vision.

The notebooks contain solved exercises, implementations, experiments, visualizations, and model comparisons. They are organized by course week to make the material straightforward to browse and review.

> **Purpose:** Academic coursework and practical learning record. The notebooks are presented as coursework rather than as a collection of production-ready software packages.

## 📚 Coursework & Notebooks

| Week | Topic | Main contents |
|:---:|---|---|
| 01 | **Python Fundamentals** | Variables, data types, lists, loops, functions, normalization, sigmoid, and a small ML pipeline challenge. |
| 02 | **NumPy & Numerical Computing** | Arrays, indexing, vectorization, broadcasting, dot products, normalization, MSE, plotting, and basic model classes. |
| 03 | **Linear Regression** | California Housing dataset, exploratory analysis, feature relationships, linear regression, SGD, and polynomial regression exercises. |
| 04 | **Classification & Neural Networks** | Logistic regression implemented from scratch, Breast Cancer Wisconsin dataset, and a PyTorch deep neural network. |
| 05 | **Data Preprocessing & Model Evaluation** | Feature scaling, outlier handling, median imputation, correlation, VIF, cross-validation, covariate shift, regularization, and learning-rate scheduling. |
| 07 | **Naive Bayes & Robust Regression** | Gaussian and t-distribution Naive Bayes, model evaluation, and robust regression experiments with outliers. |
| 08 | **Sequence Models & RNNs** | SMS spam classification, vocabulary building, dataset preparation, and recurrent neural network models. |
| 09 | **Natural Language Processing** | Named Entity Recognition (NER), vocabulary and dataset preparation, BiLSTM with attention, and Transformers. |
| 10 | **Diffusion Models & Generative AI** | Diffusion schedules, U-Net, reverse diffusion sampling, super-resolution, and image colorization. |
| 11 | **Computer Vision** | Custom CNN on CIFAR-10, ResNet transfer learning on Oxford Pets, YOLO object detection and fine-tuning, and data augmentation exercises. |

## 🧠 Topics Covered

- **Python & Numerical Computing:** Python programming, NumPy, vectorization, and data visualization.
- **Classical Machine Learning:** Linear regression, polynomial regression, logistic regression, Naive Bayes, and model evaluation.
- **Data Preparation:** Feature scaling, imputation, outlier treatment, feature correlation, VIF, and cross-validation.
- **Deep Learning:** Neural networks, optimization, regularization, and learning-rate scheduling.
- **Natural Language Processing:** RNNs, sequence modeling, text classification, NER, attention, and Transformers.
- **Computer Vision:** CNNs, transfer learning, object detection, and data augmentation.
- **Generative AI:** Diffusion models, U-Net architectures, super-resolution, and image colorization.
